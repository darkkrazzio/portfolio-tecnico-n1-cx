# Base de Conhecimento N1 (Knowledge Base - KB)

Bem-vindo ao repositório central de documentação e Procedimentos Operacionais Padrão (POP) do Service Desk N1.

## Estrutura de Artigos

Todos os artigos nesta base de conhecimento seguem o padrão estruturado:
1. **Título & Código KB**
2. **Problema & Sintomas**
3. **Ambiente Afetado**
4. **Causa Provável**
5. **Pré-requisitos**
6. **Procedimento Passo a Passo (com comandos)**
7. **Validação Técnica e com o Usuário**
8. **Medidas Preventivas**
9. **Critérios de Escalonamento (N2/N3)**
10. **Palavras-chave (Tags para busca rápida)**
