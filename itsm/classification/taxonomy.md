# Taxonomia Oficial de Categorização de Chamados N1

Para garantir precisão estatística, relatórios confiáveis e identificação rápida de problemas recorrentes, o Service Desk N1 adota a taxonomia em dois níveis:

| Categoria Primária | Subcategorias Homologadas | Exemplos Típicos |
| :--- | :--- | :--- |
| **Hardware** | Desktop, Notebook, Monitor, Teclado/Mouse, Fonte de Alimentação, Docking Station | Computador não liga, tela piscando, botão power quebrado |
| **Software** | ERP / CRM, Pacote Office / M365, Softwares Especializados, Navegadores (Edge/Chrome) | Falha ao abrir aplicativo, erro de DLL, tela branca |
| **Sistema Operacional** | Windows 10/11, Linux (Ubuntu), Inicialização (BSOD), Atualizações (Windows Update) | Disco 100%, travamento de perfil temporário, tela azul |
| **Rede & Conectividade** | Conexão Cabo (Ethernet), Conexão Wi-Fi, VPN Corporativa, Resolução DNS, Conflito IP | APIPA 169.254, perda de pacotes, erro de domínio |
| **Identidade & Acesso** | Desbloqueio de Conta, Redefinição de Senha, Criação de Usuário (Onboarding), Permissão de Pastas (SMB) | Conta bloqueada no AD, senha expirada, permissão de leitura |
| **E-mail & Mensageria** | Outlook Desktop, Webmail (OWA), Sincronização OST, Quota de Caixa de Entrada, Phishing | Outlook desconectado, anexo rejeitado por tamanho, e-mail suspeito |
| **Periféricos & Áudio** | Impressora Local, Impressora de Rede, Headset / Microfone, Scanner, Webcam de Reunião | Fila travada no Spooler, microfone mudo no Teams, vídeo sem sinal |
| **Telefonia & VoIP** | Hardphone SIP, Ramal Virtual (Softphone), Áudio Unidirecional, Queda de Ligações | Telefone não registra, erro de autenticação no ramal |
